# Engine.ini preset sources

Presets in this folder are downloaded from Nexus Mods (not bundled in git).

## Performance presets (Ghostiexd)

- **Nexus:** https://www.nexusmods.com/subnautica2/mods/51
- **Folders:** `Balanced-Performance`, `High-Performance`, `Ultra-Performance`, `Potato-PC`

## Quality presets (Vercadi)

- **Nexus:** https://www.nexusmods.com/subnautica2/mods/37
- **Folders:** `High-Quality`, `Balanced-Quality`

## Install via mod manager

- **Mod Manager → Engine Tweaks → Fetch presets from Nexus**

Requires `NEXUS_API_KEY` in `Helpers/.env` for automatic download. You can also download manually from the links above and place each `Engine.ini` in the matching subfolder.
